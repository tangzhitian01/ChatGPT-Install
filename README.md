# ChatGPT 更新工具

## 下载与运行

1. 下载 `ChatGPT-Updater-licensed.exe`。
2. 将 EXE 保存到本地可写目录，不要直接放在压缩包内运行。
3. 双击运行。首次运行把窗口显示的申请码提供给发行者，收到激活码后粘贴并点击“激活”。
4. 窗口会显示系统信息、当前版本、可用版本和详细日志。

## 签发激活码

发行者在原发证电脑上运行 `ChatGPT-License-Issuer.exe`，输入申请者提供的申请码，点击“生成激活码”，再点击“复制激活码”交给申请者。申请者将完整激活码粘贴到更新工具的激活窗口。

## 更新 ChatGPT

1. 启动工具并等待检查完成。
2. 如果显示“已安装最新版本 ChatGPT”，无需继续操作。
3. 如果发现更新，先点击“打开下载目录”检查安装包是否完整。
4. 确认文件无误后点击“安装”。
5. 按提示保存正在编辑的项目，然后确认关闭 ChatGPT/Codex 并继续安装。
6. 安装完成后重新启动 ChatGPT/Codex。

工具会保留已下载且校验通过的安装包。再次启动时，如果本地已有对应的最新安装包，将跳过重复下载。下载未完成、校验失败或取消任务时，临时文件会自动清理。

安装过程中如果提示应用正在使用，请保存工作并完全退出 ChatGPT/Codex，再点击“安装”重试。更新工具不会代替应用保存未保存的内容。

## 日志窗口

日志区域可以上下滚动查看详细信息。查看旧日志时，窗口不会强制跳到最新一行；重复的下载状态只更新进度百分比，不会不断追加相同内容。

## 被安全软件拦截

这两款 EXE 当前没有 Windows 代码签名。运行前请确认文件来自可信来源，并核对发行者提供的 SHA-256 文件哈希：

```text
ChatGPT-Updater-licensed.exe  25D74A02E5C767EAF4C959E844846B8BE47124AC1F112CBB2EE8F9FB859C6EAB
ChatGPT-License-Issuer.exe     FA05712AC406929F8F01BEA67E2E95C3D1B5BDE445D70F9DB1F62273537D1A2D
```

如果确认来源可靠但仍被拦截，请根据拦截软件的提示处理。不同 Windows 或安全软件版本的菜单名称可能略有差异。

### Windows“智能应用控制”

1. 打开“开始”菜单，搜索并打开“Windows 安全中心”。
2. 进入“应用和浏览器控制”。
3. 打开“智能应用控制设置”。
4. 记录当前状态，按系统提示选择“关”并确认。
5. 运行更新工具。
6. 测试完成后返回同一页面，按照系统提示恢复防护。

关闭智能应用控制后，部分 Windows 版本或设备可能无法直接重新启用，甚至需要更新、重置或重新安装 Windows。它不支持只对单个 EXE 放行。无法确认文件安全时，不要关闭此功能。

### 360安全卫士

1. 保存正在进行的工作。
2. 点击任务栏右下角“显示隐藏的图标”（`^`）。
3. 右键点击 360安全卫士图标，选择“退出”或“退出卫士”，按提示确认。
4. 如果安装了 360杀毒或其他安全软件，请分别查看它们的拦截记录和处理选项。
5. 运行更新工具并完成安装。
6. 测试完成后，从“开始”菜单重新启动已退出的安全软件，确认实时防护已恢复。

不要为了运行未知文件而反复降低安全设置，也不要强制结束安全软件的自我保护进程。若仍被拦截，请联系发行者获取签名版本，或通过安全软件的官方渠道提交误报。
